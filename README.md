# heapmask

Heap identifiers and mask tokens for idempotent workflows.

**Site:** https://theworker02.github.io/heapmask/

## Install / run

```bash
git clone https://github.com/theworker02/heapmask.git
cd heapmask
node src/cli.js
node --test
```
